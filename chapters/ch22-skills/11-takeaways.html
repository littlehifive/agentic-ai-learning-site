Key takeaways

Three things to carry forward

1

A skill is a package, not a tool

It bundles instructions, tools, knowledge, and guardrails for one kind of task. A tool is one function; a skill is knowing how and when to use it.

2

Load on demand to save context

Keeping every skill always on wastes the limited context window. Loading only the relevant ones lets the library grow large while the agent stays lean.

3

Compose, abstract, and reuse

Combine small skills into bigger ones, hide the wiring behind a clean interface, and share them from a library so each piece is built once.
