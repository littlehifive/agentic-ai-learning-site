22.3.3 The augmented LLM

The building block is never a bare model, it is a model plus its add-ons

Before we package skills, we need the unit they sit on. In Anthropic's framing the atomic unit of an agent is the augmented LLM: a model bundled with the retrieval, tools, and memory it needs. A skill simply decides which of these the model gets for a given task.

Model

The reasoning engine that decides what to do next.

+

Retrieval

Outside knowledge it can look up when needed.

+

Tools

Functions it can call to act on the world.

+

Memory

What it remembers across steps and sessions.

Think of it like a worker on the job. The model is the worker; retrieval is the reference manual, tools are the equipment, and memory is the notebook. A skill is the worker arriving with exactly the right set for one task.

In plain terms

Augmented LLMA model packaged with retrieval, tools, and memory; the smallest complete agent unit.
Atomic unitThe smallest piece you build agents out of, rather than the raw model alone.
