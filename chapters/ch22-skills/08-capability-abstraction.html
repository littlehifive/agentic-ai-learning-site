22.5 Skill manifests

Hide the messy details behind a clean interface

A skill exposes a simple front door, its name, what it does, and what goes in and out. The complicated parts, the prompts, the tools, the version, sit behind that door. Whoever uses the skill needs the front door, not the wiring.

The clean face: a skill manifest

  • Name and a one-line description
  • What it expects in, and gives back
  • A version number you can pin

The hidden machinery

  • The system prompts and few-shot examples
  • The tools and MCP servers it calls
  • The guardrails and validation rules
Think of it like a power socket. You plug in and it works. You do not need to know how the grid routes electricity to your wall, only the shape of the plug.
