How is a skill different from a tool?

Reveal ▸

A tool is a single function the agent can call. A skill is a whole package for one kind of task: instructions, the tools it needs, reference knowledge, the workflow, and guardrails, all bundled so the agent knows how and when to use it.

Why load skills dynamically instead of all at once?

Reveal ▸

Every loaded skill takes up the agent's limited context window. Loading only the skills that match the current task keeps context lean and lets the skill library grow to hundreds of entries. The cost is a small chance the router misses a relevant skill.

What is the augmented LLM, and how does it relate to skills?

Reveal ▸

It is the atomic unit of an agent: a model plus retrieval, tools, and memory, never the bare model alone. A skill is just a choice of which retrieval, tools, and memory the model gets for a particular task.
