22.1 Skill vs. tool vs. agent

Three levels, from a single action to a full worker

Skills sit in the middle of a ladder. Below them is the single tool call. Above them is the agent that decides which skills to reach for.

Level 1

Tool

A single function call. It does one narrow thing and returns a result.

Example: a web search call that takes a query and returns links.

Level 2

Skill

A coherent capability: instructions plus the tools and knowledge for a kind of task.

Example: a "research analyst" skill that searches, reads, and summarizes.

Level 3

Agent

An autonomous worker that holds several skills and chooses which to apply.

Example: a coding assistant that reviews, tests, and documents code.

Think of it like a building site. A tool is a hammer. A skill is knowing how to frame a house. The agent is the carpenter who decides which skill to apply, and when.
