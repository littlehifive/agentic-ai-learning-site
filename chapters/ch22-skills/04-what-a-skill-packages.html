22.1 What is a skill?

A skill is more than a tool: it bundles everything to do one job well

A raw tool exposes a single function. A skill wraps that function with the surrounding know-how, so the agent does not just have the equipment, it knows how and when to use it.

InstructionsDomain guidance, constraints, and persona added to the agent's context.
Tool bindingsThe specific tools, APIs, or MCP servers the skill needs to act.
KnowledgeReference material and worked examples that show what good looks like.
Workflow logicThe multi-step procedure or decision flow for the task.
GuardrailsSafety limits, output format rules, and checks on the result.
Think of it like a recipe card, not a single utility. A tool is the whisk. The skill is the whole card: the ingredients, the steps, the tips, and the note on how to tell when it is done.

In plain terms

ToolOne function the agent can call, like web_search.
SkillA coherent capability: instructions plus tools plus knowledge, packaged together.
