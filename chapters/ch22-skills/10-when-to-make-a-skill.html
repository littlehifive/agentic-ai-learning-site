22.6 Skills vs. fine-tuning

When should a capability become a skill?

Skills add expertise at runtime; fine-tuning bakes it into the model. They are complementary, but the choice of which to use comes down to how fast you need it and how often it changes.

Reach for a skill when

  • You want it live now, not after hours of training
  • The task expertise changes often, or differs per user
  • You want to swap or combine capabilities at runtime
  • Each piece stays narrow and well-defined, so it composes

Lean on fine-tuning when

  • You need a deep, permanent change in behavior
  • The capability is stable and shared by everyone
  • You want zero runtime cost in the context window
  • You are teaching base skills like the tool-use format itself
Think of it like a reference book versus going back to school. A skill is the manual you grab off the shelf today. Fine-tuning is the training that becomes second nature, but takes far longer to acquire.
