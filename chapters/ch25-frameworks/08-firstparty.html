The first-party options from the model makers

The companies that build the models also ship their own lightweight kits. They aim for the smallest amount of glue between you and their platform, and they lean on emerging standards so existing APIs become agent tools with little or no extra code.

OpenAI Agents SDK

A small Python library for routing work between specialist agents. The core move is a handoff: one agent transfers control to another, passing the context along. Guardrails can screen a request before it runs, and tracing is built in. Best when you are already on OpenAI's platform and want minimal scaffolding.

Google ADK and the OpenAPI shortcut

Google's kit, among others, can turn an OpenAPI specification, the standard description of a REST API, straight into agent tools. Point it at the spec and each endpoint becomes a function the model can call. Any team with documented APIs can make them agent-accessible with no extra wrapper code.

Think of it like buying appliances from the same brand as your kitchen. They are made to click in with the least adapters, and they read the manuals your existing gear already came with.
