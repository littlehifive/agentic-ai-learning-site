25.3.1 LangGraph

Draw the agent as a map of steps

LangGraph treats an agent as a graph: boxes are steps and arrows are the moves between them. A shared, typed state flows from box to box, and each arrow can branch on what the state says. Because the whole flow is drawn out, you can reason about it, test it, and pause it at any point.

Think of it like a board game with a printed board. Every square is a step, the arrows are the legal moves, and your piece carries a record of what has happened so far. Nothing is hidden in the rulebook's head.

In plain terms

NodeOne step: it reads the shared state and returns an update to it.
EdgeA move from one step to the next, which can branch based on the state.
CheckpointingSaving the state after each step, so the agent can pause, wait for a human, and resume.
