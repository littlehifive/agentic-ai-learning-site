25.3.2 AutoGen (Microsoft)

Let agents talk it out in a group chat

AutoGen treats agents as participants in a conversation. Instead of one fixed loop, several specialists, say a planner, a coder, and a critic, share a chat and take turns. A manager decides who speaks next. A distinctive feature is that one participant can actually run code, test it, and fix it before reporting back.

Think of it like a war room on a group call. A facilitator picks the next speaker, the experts debate, and one person at the keyboard can run the numbers live and read the result back to the room.

In plain terms

Conversable agentA participant with a role, set by its system message, that speaks in the shared chat.
Group chat managerThe facilitator that decides whose turn it is, by round-robin or by asking the model.
Code executionAn agent that runs code in a sandbox; in production, keep it isolated in a container.
