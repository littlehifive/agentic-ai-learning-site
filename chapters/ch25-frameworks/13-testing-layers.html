25.5 The agent testing pyramid

Test in layers, from small and cheap to big and sure

No single test catches everything, so you stack them. The lower layers are fast and run often; the upper layers are slower but give you more confidence the whole agent behaves. Most teams need all four.

The cheap, frequent layers

  • Unit tests check each tool alone: the normal case, the error case, and the odd edge cases.
  • Integration tests run the full loop with stand-in tools, checking it orchestrates them correctly, for example searching before writing.

The slower, surer layers

  • Golden trajectories save a known-good run and flag if a new run drifts in its tool sequence, its answer, or its cost.
  • Behavioural tests confirm it follows the rules: refuses harmful requests, respects call limits, stays on allowed sites.
Think of it like a car factory. You test each part on the bench, then the assembled engine, then a full test drive, then the safety inspection. Skipping a layer just moves the surprise to a worse moment.
