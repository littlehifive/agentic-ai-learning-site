28.6 · Hyperparameter ranges, sensible starting points

Training defaults to start from

If you change nothing else, these are the values that usually just work. Tune from here, not from scratch.

KnobDefaultWhat it does, and why this value
OptimizerAdamWThe standard choice that adapts each weight's step size and gently shrinks weights to avoid overfitting.
Number formatBF16A 16-bit format with wide range: half the memory of full precision, and safer than the FP16 alternative.
Learning rate, fine-tune2e-5How big each update is. This is the workhorse value for supervised fine-tuning of a base model.
Learning rate, alignment5e-7Much smaller for reinforcement-learning alignment, since the model is already good and easy to break.
LoRA rank and alphar = 16, α = 2rAdd-on size and its scaling. The effective strength is alpha over r, so alpha at twice r is a safe default.
Gradient clip norm1.0Caps any single update that grows too large, stopping a rare spike from blowing up training.

In plain terms

Learning rateThe size of each step the model takes while learning. Too big destabilizes; too small wastes time.
2e-5Shorthand for 0.00002. The "e-5" just means "move the decimal five places left".
