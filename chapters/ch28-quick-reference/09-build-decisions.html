Build decisions · the three questions you face first

What to build, decided fast

Before any code, three forks set the shape of the system. Default to the simpler side unless you need the other.

Workflow or agent?

WorkflowDefault. Fixed steps you can draw in advance. Cheaper, predictable, easy to debug.
AgentOnly when the path cannot be known up front and the model must decide its own next move.

One agent or many?

SingleDefault. Simplest to build and reason about. Stretch one agent first.
MultiOnly with clear subtask boundaries or distinct skills, since coordination adds cost and failure modes.

RAG or fine-tune?

RAGDefault for facts. Knowledge that changes or must be cited; update by changing documents.
Fine-tuneFor changing behavior, format, or style, not for adding fresh facts.

In plain terms

Workflow vs agentA workflow follows a script you wrote. An agent writes its own next step as it goes.
RAG vs fine-tuneRAG changes what the model knows. Fine-tuning changes how the model behaves.
