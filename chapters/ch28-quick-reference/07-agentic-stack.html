28.9, 28.16 · What an agent is made of

The agentic stack, layer by layer

An agent is a model wrapped in supporting parts that let it perceive, remember, act, and coordinate.

The layers

  • Grounding (RAG): pull in outside facts so answers rest on real sources, not guesses.
  • Memory: working memory in the prompt, plus longer stores for past sessions and learned facts.
  • Harness: the loop that runs the agent: think, act, observe, repeat, with limits and guards.
  • Tools: the functions the agent can call to do things in the world, from search to writing files.
  • Multi-agent: several specialized agents that split a job and hand work between them.

Design patterns

  • ReAct: think, act, observe, loop. The default for general tool use.
  • Plan-and-execute: plan all the steps first, then carry them out. For long, structured tasks.
  • Supervisor: a router sends each subtask to the right specialist agent.
  • Swarm (handoffs): agents pass control and context along, as in support escalation.
  • Human-in-the-loop: the agent pauses for approval before high-stakes, irreversible actions.

In plain terms

HarnessThe scaffolding around the model that turns one answer into a repeating act-and-observe loop.
GroundingGiving the model real source material to base its answer on, instead of relying on memory alone.
