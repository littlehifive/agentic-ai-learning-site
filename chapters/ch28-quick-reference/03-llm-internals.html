Encodes position by rotating each word's vector, so the model knows word order without a separate position table.

GQA

Several attention heads share one set of keys and values, cutting generation memory roughly fourfold at almost no quality cost.

Mixture of Experts

Many small expert sub-networks, but only a few fire per word, so the model is large in skill yet cheap to run.

Freeze the base model, learn a tiny add-on, and capture a new skill for under one percent of the size.
