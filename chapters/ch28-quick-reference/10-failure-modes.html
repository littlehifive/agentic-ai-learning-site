Common failure modes and first fixes

Match the symptom you see to its usual cause, then try the fix on the right.

SymptomLikely causeFirst fix to try
Reward up, quality downThe model gaming the scoreAdd a length penalty, raise the conservatism setting.
Training loss becomes NaNGradients explodedLower the learning rate, tighten gradient clipping, check the data.
Out of memory while generatingThe KV cache overflowedSmaller batch, more parallelism, paged attention.
Agent loops foreverNo stop conditionSet a max-iterations cap, add loop detection.
Tool calls fail to parseInconsistent output formatFew-shot examples, constrained decoding.
RAG returns irrelevant docsPoor embeddings or chunkingAdd a reranker, hybrid search, smaller chunks.
Prompt injection in tool outputTrusting retrieved textTreat tool output as untrusted; ignore instructions inside docs.
