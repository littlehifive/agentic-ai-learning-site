14.5.6 Pass@k for Code

Pass@k: did at least one of k tries pass the tests?

For code, correctness is not a matter of opinion: you run the code against tests. Pass@k asks the model for k attempts at a problem and counts it solved if any single attempt passes every test.

Try 1fails tests
Try 2fails tests
Try 3passes all
Try 4fails tests
pass@4 = solved
Think of it like free throws in basketball. Pass@1 is making the first shot. Pass@10 is making at least one out of ten. More attempts means a higher chance that one lands, so always read which k a score refers to.

In plain terms

Pass@1The model gets one shot. The honest measure of first-try reliability.
Pass@10, pass@100Allow more attempts. Useful when a human or a tool can pick the working one.
Why it is trustedTests decide pass or fail, so the metric tracks real correctness, not surface polish.
