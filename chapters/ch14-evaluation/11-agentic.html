14.6 Metrics for Agentic Tasks

For agents, ask: did the task actually get done?

An agent does not just write text. It takes a series of actions in an environment, clicks, calls tools, edits files. Polished prose is not the point. The question is whether the world ended up in the goal state.

The wrong question

Does the answer read well? An agent can describe a perfect plan to fix a bug and still leave the bug in place. Fluent text is no proof of a finished job.

The right question

Was the goal achieved? A checker inspects the result: did the tests pass, did the file change, did the item land in the cart. Pass or fail, verified.

Think of it like hiring a plumber. You do not grade the explanation of how they will fix the leak. You check whether the leak stopped.

In plain terms

Task success rateThe fraction of tasks where a checker confirms the goal was reached. The headline metric for agents.
SWE-benchReal GitHub issues: the agent must write a patch that makes the project's test suite pass.
Trajectory efficiencyDid it reach the goal in few steps, or wander? Fewer wasted actions is better.
