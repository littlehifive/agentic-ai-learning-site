4.1 Paradigm 2: verifiable rewards

RLVR: let a checker grade the answer, not a person

For tasks with a right answer, you do not need a learned judge at all. Run the model's output through a verifier: solve the math, run the tests, match the final answer. Correct earns reward, wrong earns none. This is RL from Verifiable Rewards, and it is now the standard way to build reasoning models.

Prompt

A math or coding problem with a known correct outcome.

→

Model attempts

It reasons step by step and writes a final answer or a block of code.

→

Checker verifies

An automatic check decides pass or fail. No human in the loop.

tests passed: reward = 1
Think of it like a self-grading exam with an answer key. Because the key is exact and cheap to run, you can grade millions of attempts a day, and there is almost nothing for the model to fake. DeepSeek-R1 learned to reason this way using rule-based rewards and no human preference data at all.

In plain terms

VerifierA program that checks correctness directly: a test suite, a math comparison, a format rule.
Where it fitsOnly where outcomes are checkable: math, code, logic. For taste and tone you still need human preferences.
