16.3.3 Hybrid retrieval with Reciprocal Rank Fusion

Run both searches, then merge their rankings

Keyword search and meaning search each have blind spots. Hybrid search runs both, then blends their results. The trick is that their scores are on different scales, so you cannot just add them.

Keyword search (BM25)

Matches exact words. Unbeatable for product codes, error codes, names, and rare terms, and it needs no special hardware.

Meaning search (vectors)

Matches ideas even when the wording differs. Strong on paraphrases and synonyms, but it can miss an exact string.

Each returns a ranked list Reciprocal Rank Fusion combines them by position, not score
Think of it like two judges scoring the same contest on different scales. Rather than averaging raw points, you trust their ordering: an entry both rank near the top wins. RRF rewards passages that place highly on either list.

In plain terms

BM25A long-trusted keyword scoring formula that favours rare, exactly matched terms.
Reciprocal Rank FusionMerges lists using each item's rank, so mismatched score scales do not matter.
