10.6 SFT best practices summary

The habits that make fine-tuning pay off

Most of the value comes from a short checklist applied consistently. These four cover the everyday decisions that separate a clean fine-tune from a wasteful or brittle one.

Clean, varied dataA small set of excellent, diverse examples beats a large noisy one. Make sure it covers every task you care about.
Mask and template rightGrade only the response, and wrap each turn in the exact chat template your model family expects.
Pack for efficiencyPack short examples together instead of padding, to cut wasted compute by two to four times.
Stop early, protect skillsTwo to three epochs is enough; use light adapters to guard the base model from forgetting.

In plain terms

AdapterA small add-on trained on top of a frozen base model, so the original knowledge stays safe.
Check before you scaleConfirm the model can already answer some hard cases before pushing it through later tuning, since that tuning cannot create a missing skill.
