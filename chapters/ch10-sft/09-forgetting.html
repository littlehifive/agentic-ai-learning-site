10.5 When SFT hurts

Teaching one narrow skill can erase others

Fine-tuning hard on a single task, say chat, can overwrite the knowledge the model already had, like math or other languages. The old skill is not hidden, it is gone, because the same internal settings that stored it got rewritten. This is called catastrophic forgetting.

Think of it like repainting a wall. Roll fresh paint over an old mural to make room for a new picture, and the mural underneath is gone for good, not just covered up. You would have to repaint it from scratch.

In plain terms

Catastrophic forgettingTraining on a new task overwrites the settings that stored an old one, destroying it.
Telltale signThe model completely fails at a task it used to handle, like forgetting math after chat tuning.
How to soften itMix in a little old data, use a gentle learning rate, and train light adapters that leave the base model frozen.
