Chapter 10 · SFT Best Practices and Techniques

SFT is the first teaching step after pre-training

A fresh model can only continue text. Supervised fine-tuning, SFT for short, is where it first learns to follow instructions and answer in a useful format. It sets the ceiling for everything that comes after: reward-based tuning can polish a skill but cannot add one the model never learned here.

Stage 1

Pre-training

The model reads a huge pile of text and learns to predict the next word. It knows a lot but does not yet take instructions.

→

Stage 2 · this chapter

Supervised fine-tuning

The model copies thousands of example prompts and answers, learning to follow instructions and reply in the expected style.

→

Stage 3

Reward-based tuning

The model practises against human preferences, amplifying good behaviour. It can only build on what SFT already taught.

In plain terms

SFTSupervised fine-tuning: teaching by imitation, where the model copies many correct prompt-and-answer examples.
SFT sets the ceilingLater tuning can strengthen a skill that is present but weak; it cannot create a skill that was never taught.
