10.3 Completion-only masking

Grade the model only on its answer, not the question

Each training example is a prompt followed by a response. We only want the model to learn how to answer, not how to write the user's question back. So we ignore the prompt tokens when scoring and only correct the model on the response it is supposed to produce.

Prompt · ignoredWhat is the capital of France? Response · learnedThe capital of France is Paris.
Think of it like grading a worksheet. The questions are already printed on the page, so you only mark the student on the answers they fill in, not on copying the questions back.

In plain terms

MaskingTelling the model which tokens count toward the lesson and which to skip.
Why it helpsIt focuses the correction on response quality and stops the model from just memorising prompts.
Watch outIf a response is very short, masking the prompt can leave too little to learn from; and every assistant turn in a chat must be unmasked, not just the first.
