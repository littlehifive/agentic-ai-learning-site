How does agentic RAG differ from standard RAG?

Reveal ▸

Standard RAG is a fixed pipeline: query, retrieve, generate. Agentic RAG treats retrieval as an action: the agent decides whether to retrieve, plans sub-queries, grades the results, and retrieves again if they fall short. More accurate on hard queries, but slower due to extra model calls.

What are the four types of agentic memory?

Reveal ▸

Working memory is the current scratchpad in context. Episodic memory stores past experiences, retrieved by similarity. Semantic memory holds facts, retrieved by concept. Procedural memory holds learned skills, triggered by task type. They interact: episodes feed facts, and working memory orchestrates the rest.

What is the context budget problem?

Reveal ▸

System prompt, memory, tool descriptions, history, and reserved response space must all fit one window. As conversations grow, history crowds out the rest. Solve it by summarizing old turns, loading only relevant tools, fetching memory on demand, and counting tokens before every call.
