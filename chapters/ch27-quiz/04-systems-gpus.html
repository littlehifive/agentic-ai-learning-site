Where the hardware sets the limits

What problem does Flash Attention solve, and how?

Reveal ▸

Plain attention writes a huge score grid to slow memory, so the chip mostly waits on data. Flash Attention never stores the full grid: it works in small tiles inside fast on-chip memory using an online softmax. The result is exact, uses far less memory, and runs 2 to 4 times faster.

What does PagedAttention fix in KV cache serving?

Reveal ▸

Pre-allocating the full max length per sequence wastes most of the cache. PagedAttention borrows from operating systems: it splits the cache into fixed blocks mapped by a block table, allocated on demand. This nearly removes waste and fits 3 to 5 times more sequences in the same memory.

When do you use NVLink versus InfiniBand in training?

Reveal ▸

NVLink is the ultra-fast link between GPUs inside one node, used for tensor parallelism where layers sync after every step. InfiniBand connects nodes across the cluster, used for data parallel and FSDP gradient syncs that happen once per training step, so they tolerate more latency.
