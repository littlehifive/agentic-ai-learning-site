Teaching a model to reason

Why does DeepSeek-R1 skip a process reward model?

Reveal ▸

Math and code have verifiable ground-truth answers, so a binary accuracy reward gives enough signal even for long chains. Process models add their own hacking, where steps look correct without being correct. GRPO's group normalization already provides relative signal about which chains worked.

Distillation versus direct RL for small reasoning models?

Reveal ▸

Distillation fine-tunes the small model on reasoning chains from a large one: cheap, but it can copy surface patterns. Direct RL lets the small model discover its own strategies, at much higher compute. In practice, distilling first then optionally adding RL gives the strongest result.

How does SFT quality cap what RL can achieve?

Reveal ▸

RL only reinforces behaviors the model can already produce with some probability. If the base never generates a correct solution, there is nothing for RL to amplify. The pass@k diagnostic tests this: generate k samples and check if any is correct, which estimates the ceiling RL can reach.
