Why is a GPU faster than a CPU for running models?

Reveal ▸

A model's work is the same simple multiplication repeated billions of times. A CPU has a few fast lanes; a GPU has thousands of small ones running at once, which is exactly the shape of that work, making it 100 to 1000 times faster.

What does memory-bound mean, and why does it matter?

Reveal ▸

It means the math units sit idle waiting for data to arrive, because the job does little math per number fetched. It matters because the fix is to move less data or reuse it more, not to add raw compute power.

How does PagedAttention let a GPU serve more users?

Reveal ▸

It stores each reply's notes in small pages handed out only as needed, instead of reserving a big block per reply. That removes the wasted space, so far more replies fit in the same memory at once.
