2.1.10 Choosing Parallelism Based on Bandwidth

Match the split to the speed of the link

The rule of thumb is simple: the more often a split needs to exchange data, the faster the cable it needs. Chatty splits stay inside one machine on NVLink. Quieter splits can stretch across the network.

Keep inside one machine (NVLink)

  • Tensor parallel: exchanges data every single layer, so it demands the fastest link. Standard setup is 8 GPUs in one box.
  • Anything that talks constantly belongs here, where bandwidth is 28 times higher than the network.

Can cross machines (network)

  • Data parallel and FSDP: sync once per step, so the slower network is fine, and they scale well across many machines.
  • Pipeline parallel: only hands off at stage boundaries, so it too can span machines when a model is huge.
Think of it like seating a project team. People who talk every minute sit at one table (tensor parallel on NVLink). Teams that only sync at daily standup can work in separate buildings (data parallel across the network).

In plain terms

BandwidthHow much data a link can carry per second; it decides which splits can live where.
SyncThe moment GPUs pause to share results; doing it less often makes slower links acceptable.
