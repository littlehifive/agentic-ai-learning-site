2.2.1 The KV Cache Fragmentation Problem

Serving fast means managing the model's short-term memory

Reserve max length per request

Solid = words actually written. Striped = space reserved but never used. Real systems waste 60 to 80% of memory this way.

As a model writes a reply, it keeps a running set of notes on every word so far, called the KV cache. It is the single biggest memory user during serving. The old approach reserved a big block for each request, sized for the longest possible reply. Most replies are short, so most of that reserved space sits empty and unusable.

Think of it like a restaurant that blocks a 12-seat table for every booking, even parties of two. The room fills with half-empty tables, and you turn away guests with nowhere to sit.

In plain terms

KV cacheThe model's running notes on every word so far in a reply; the main memory user when serving.
FragmentationMemory wasted because it was reserved in big fixed blocks that go mostly unused.
