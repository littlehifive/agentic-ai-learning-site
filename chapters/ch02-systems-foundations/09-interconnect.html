2.1.10 Communication Architecture: NVLink, InfiniBand, PCIe

Big models need many GPUs talking constantly

One GPU cannot hold the largest models, so dozens or hundreds share the work, and they must swap results many times a second. The cable between them then becomes the bottleneck. There are three tiers, from a blazing-fast link inside one machine down to the network between machines.

Same machine

NVLink + NVSwitch

900 to 1800 GB/s

A dedicated high-speed link between GPUs in one box. NVSwitch lets every GPU talk to every other at full speed at once, not just its neighbors.

Between machines

InfiniBand

~50 GB/s per port

A fast network joining separate servers into one cluster. GPUs can even read each other's memory across the network without bothering the CPU.

CPU to GPU

PCIe

~32 GB/s

The general-purpose link to the rest of the computer. Far slower, so never use it for GPU-to-GPU traffic when NVLink is available.

Think of it like moving between desks in one office (NVLink), driving across town between offices (InfiniBand), and mailing a letter to the loading dock (PCIe). Same goal, wildly different speeds.

In plain terms

NVLinkA very fast direct link between GPUs inside the same machine.
NVSwitchA hub so all GPUs in a box can talk to all others at full speed at the same time.
InfiniBandThe fast network that connects separate servers into one large cluster.
