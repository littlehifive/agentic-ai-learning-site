12.1 From chatbots to autonomous agents

An agent runs one small loop, over and over

A chatbot takes a prompt and returns a reply in one shot. An agent works in steps: it thinks about what to do, acts by calling a tool, then observes what came back. That result changes the next decision, and the loop turns again until the task is finished.

Think

Plan the next move

Reason about what to do, using everything seen so far.

→

Act

Use a tool

Search, run code, edit a file, call an API.

→

Observe

Read the result

Tests pass or fail, a page loads, an error appears.

↻ Repeat for 10 to 100+ steps, until the task succeeds or gives up

Think of it like a cook following a recipe rather than answering a trivia question. Each action changes the kitchen, and the next step depends on what just happened on the stove.

In plain terms

AgentA model that takes actions over many steps to reach a goal, not just one reply.
ToolAn external action the agent can take: web search, code execution, a database query.
ObservationWhat the environment hands back after an action, which guides the next step.
