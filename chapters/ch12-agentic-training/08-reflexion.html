12.5.2 Reflexion: verbal reinforcement learning

The model writes itself a note, then tries again

Reflexion improves without changing a single weight. When an attempt fails, the model writes a short plain-language critique of what went wrong. That note is saved and pasted into the prompt on the next try, so the model carries forward the lesson it just learned.

A self-written reflection after a failed attempt

"I called the search API before checking the input format, which caused an error. Next time I should validate the data first, then make the call."

Think of it like a sticky note on your monitor that says "remember to save before you run it." Nothing about you changes, but you read it next time and avoid the same mistake.

In plain terms

No weight updateThe model itself stays frozen; all the improvement lives in the notes added to its prompt.
Episodic memoryA short buffer of recent reflections, usually only the last few, since they must fit in the prompt.
LimitThe lessons are specific to the task at hand and do not transfer to brand-new problems.
