12.5.7 RLEF: RL from execution feedback

The cleanest reward is whether the code actually runs

RLEF is where the field is converging. The agent writes a solution, the test suite runs it, and the share of tests that pass becomes the reward. No human raters, no learned grader to fool, just the plain verdict of execution feeding back into training.

Zero noise

The same code gives the same result every time, so the reward never wobbles.

Endless tasks

New problems with tests can be generated by the thousand, automatically.

Hard to game

A well-written test cannot be flattered or talked around; the agent must really solve it.

Dense signal

Passing six of ten tests scores higher than zero, which guides learning better than pass or fail.

Think of it like grading an exam with an answer key instead of a panel of judges. The key is fast, consistent, and impossible to charm, so everyone learns from an honest score.

In plain terms

Execution feedbackA reward that comes from running the work, not from an opinion about it.
The converging recipeOnline RL, trajectory-level rewards from real execution, and a curriculum from easy tasks to hard.
