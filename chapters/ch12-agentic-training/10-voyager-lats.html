12.5.6 Voyager · 12.5.4 LATS

Two more ways to get better: remember and search

STaR and Reflexion improve the model itself. These two improve what surrounds it. Voyager keeps a growing toolbox of proven skills, while LATS spends extra thinking time exploring several paths before committing to one.

VoyagerBuild a reusable skill library

Each time the agent writes code that solves a task and passes its check, that snippet is saved as a named skill. New tasks retrieve and combine the most relevant saved skills, so the agent keeps getting more capable and never forgets what it has already mastered.

LATSSearch over possible trajectories

Instead of committing to the first move, LATS expands several candidate actions, plays each forward to see how it turns out, and pushes the result back up a tree. It spends more compute at decision time to find a much better path.

Think of it like a cook's recipe box versus thinking three moves ahead. Voyager is the box of dishes you have nailed before; LATS is mentally tasting a few versions of the sauce before you serve one.

In plain terms

Skill libraryA store of verified code snippets the agent can retrieve and snap together for new tasks.
Tree searchTrying out several action paths and keeping the most promising one, at the cost of more compute.
