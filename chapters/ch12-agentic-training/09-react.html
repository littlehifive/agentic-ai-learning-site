12.5.3 ReAct: reasoning plus acting

Interleave a thought, then an action, then repeat

ReAct is the dominant pattern for tool-using agents. In one stream the model alternates between thinking out loud and taking an action, reading each observation before the next thought. The visible reasoning acts as an inner monologue that stops it from acting on impulse.

Thought I need the iPhone's release date, then who was president then. Let me search.
Action search("iPhone original release date")
Observation The original iPhone was released on June 29, 2007.
Action finish("George W. Bush was president in June 2007.")
Think of it like talking yourself through a repair out loud. Saying "first check the fuse" before you reach for it keeps you from grabbing the wrong tool, and it leaves a trail anyone can follow.

In plain terms

ThoughtPrivate reasoning about the next move; it is not executed.
ActionA tool call that actually runs in the environment.
ObservationThe environment's reply, added to the context to guide the next thought.
