Why does a model need a harness at all?

Reveal ▸

A model only turns text into text. It has no memory, no clock, and no way to act. The harness adds those: it holds memory, runs tools, tracks state, and recovers from errors, turning the model into an agent.

What happens when the context window fills up?

Reveal ▸

The harness must compact the history. It summarizes the oldest turns and keeps the most relevant and recent ones, while pinning the system prompt and original task so they are never dropped. Otherwise the model silently loses context.

How does the harness keep an agent from spinning forever?

Reveal ▸

It caps the number of steps, fingerprints each tool call to catch repeats, and checks whether the state is changing. If the agent stops making progress, it breaks the loop and reports what it has so far.
