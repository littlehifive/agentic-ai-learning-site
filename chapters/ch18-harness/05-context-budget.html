18.2 Context window management

The context window is a fixed budget

The context window is the agent's working memory. Every token in it costs money and time, and every token not in it is invisible to the model. The window has a fixed size, but it must hold several things that all compete for room.

System10%
Memory and RAG20%
Tools10%
History50%
Output10%
0 tokensOne fixed windowThe limit, for example 128,000 tokens
Think of it like a moving truck of fixed size. The instructions, the notes, the tools, and the room left for the answer all have to fit. The conversation history keeps growing, so something must be left behind once the truck is full.
