18.5.1 ReAct loop (reason and act)

Think, act, observe, then think again

The most common way an agent runs is a tight loop. The model reasons about what to do, takes one action with a tool, reads the result, and uses it to decide the next move. It repeats until the task is done.

Thought

Reason

The model thinks on a private scratchpad about what to do next.

→

Action

Act

It picks one tool and the arguments to call it with.

→

Observation

Observe

The harness runs the tool and feeds the result back in.

→

Stop

Finish

When the model gives a final answer, the loop ends.

Not done yet? Feed the observation back and start the next thought

In plain terms

ScratchpadThe model's private reasoning, kept in context but not shown to the user.
TerminationThe loop stops on a final answer, a stop token, or a hard cap on steps.
