Key takeaways

Three things to carry forward

1

The harness is the agent

The model only reasons. The runtime around it manages memory, dispatches tools, tracks state, and recovers from errors. That runtime is what turns a model into an agent.

2

Context is a fixed budget

The window holds a fixed amount, shared across system, tools, memory, and history. Count tokens, compact old turns, and never let it silently overflow.

3

Plan for failure

Agents get stuck and tasks go wrong. Cap the loop, detect repeats, ask a human at the risky moments, and log everything so you can see what happened.
