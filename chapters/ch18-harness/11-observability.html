18.7.4 Observability

You cannot debug what you cannot see

Agents are hard to debug because failures are usually bad decisions, not crashes. The fix is to record everything the agent does, so you can replay a run and find the exact step where it went wrong.

Traces

An end-to-end timeline of one run, with a span for every model call, tool call, and state change.

Logs

A structured record of each event: the prompt sent, the response, the tool used, with token counts, latency, and cost.

Metrics

The big-picture numbers across many runs: success rate, steps per task, tool error rate, and cost per task.

Think of it like a flight recorder. When something goes wrong, you do not guess. You replay the black box second by second to see exactly what the system saw and what it decided.

In plain terms

TraceA step-by-step recording of a single agent run that you can replay later.
Replay toolingRe-running a past trace with a tweaked prompt or model to compare the outcomes.
