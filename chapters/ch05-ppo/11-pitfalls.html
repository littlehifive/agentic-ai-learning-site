5.9 Common failure modes

Four ways PPO quietly goes wrong

1 Reward hacking. The model finds a cheap way to score high that misses the point, like padding, flattery, or canned phrases. If the leash is too loose, it exploits the scorer instead of getting genuinely better.
2 KL collapse. Tighten the leash too far and the model is stuck at its starting point, too scared to change, so it never actually learns from the reward.
3 Overusing one batch. Squeeze too many passes out of the same answers and the model overfits to that batch, while the safety math goes stale because the answers no longer match the changed model.
4 A miscalibrated reward model. The scorer is only a stand-in for human taste. If it is wrong, PPO faithfully optimises the wrong target, and the model gets confidently worse.
