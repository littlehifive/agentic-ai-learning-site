5.1 Motivation and history

Plain reward learning has no brakes

The simplest way to learn from rewards just pushes the model harder toward whatever scored well, with no limit on how big each push can be. One unlucky batch can shove the model into a region where it produces nonsense, and from there it cannot find its way back.

A big, careless step moves the model far from where it was.

→

In this untested region it starts generating garbage.

→

Garbage earns low rewards, which look like new lessons.

→

Collapse. Each step makes it worse, with no way to recover.

Think of it like turning a steering wheel as hard as you can at every correction. You do not gently track the road, you swerve off it, and once you are in the ditch the next yank only digs you deeper.

In plain terms

PolicyThe model itself, seen as the thing that chooses each next token.
Policy gradientThe basic recipe: push the model toward choices that earned higher reward.
CollapseAn update so large the model breaks and cannot be trained back to health.
