24.7.3 Centralized training, decentralized execution

Coach with the full picture, then play with your own eyes

When agents learn together, each one keeps changing, so the world looks unstable to every other agent. The fix that works best for cooperative teams is to train with a god's-eye view of everyone, but run each agent on only what it can see on its own.

During training

A central coach watches the whole game: the full state and every agent's action. With that complete view it can tell each agent how its moves actually affected the shared outcome, which steadies the learning.

During execution

The coach goes home. Each agent acts on only its own local observation, with no need to talk to a central brain at run time. So you get stable training and independent, fast agents in the field.

Think of it like a sports team. In practice the coach sees the whole field and corrects every player. On game day the coach is on the bench; each player reads the play from their own position and acts. The lessons learned with the full view carry over.
