24.2.4 Swarm architecture

Agents pass control peer to peer

No manager and no shared memory. Each agent follows simple local rules and, when a request is outside its lane, it hands off control and the needed context to a better-suited peer. The task gets done through a chain of handoffs, each agent adding its specialty. Lightweight, with no orchestration overhead.

Triage agent → hands off Billing specialist → hands off Technical support
Think of it like a customer-service phone tree run by people, not menus. Whoever picks up either answers you or transfers you, with your details, to the right desk. No supervisor is listening in; each person just knows when to pass you along.

In plain terms

HandoffOne agent transferring control, plus the relevant context, to another agent.
RoutineThe short set of instructions an agent follows to handle its part.
No global stateEach agent keeps only its own local context; nothing central tracks the whole job.
