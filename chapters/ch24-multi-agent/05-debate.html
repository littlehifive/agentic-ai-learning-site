24.6.1 Debate pattern

Agents argue to reach a better answer

Several agents take different positions on the same question, then read each other's arguments and push back. After a round or two, a separate judge agent weighs the arguments and decides. Forcing answers to survive cross-examination catches errors a lone agent would miss.

Agents state positions → They rebut each other → Repeat a round → Judge decides
Think of it like a review panel cross-checking each other. One reviewer alone can be confidently wrong; a panel that has to defend its claims out loud, with a chair to call the result, lands closer to the truth.

In plain terms

DebateAgents argue opposing positions; the disagreement surfaces flaws and hallucinations.
Judge agentA neutral agent that reads the final arguments and picks the verdict.
CostSeveral agents plus several rounds use far more compute than one answer.
