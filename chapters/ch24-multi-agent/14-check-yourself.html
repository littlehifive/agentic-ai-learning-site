When should you use a team of agents instead of one?

Reveal ▸

Only when the task splits into clearly separate roles, or needs more context than one agent can hold at once. Below that bar, a single well-designed agent is simpler, cheaper, and easier to debug.

How does a supervisor architecture differ from a swarm?

Reveal ▸

A supervisor is a hub: one lead agent delegates to workers and combines results. A swarm has no center; agents pass control peer to peer through handoffs. The hub is easy to debug; the swarm is lighter and more resilient.

What does CTDE mean, and what problem does it solve?

Reveal ▸

Centralized training, decentralized execution. Train with a god's-eye view of every agent so learning stays stable, then run each agent on only its own local view. It tames the instability of many agents learning at once.
