7.5 Variants and extensions

A family of small, targeted fixes

Once GRPO was in wide use, practitioners hit specific snags. Each named variant keeps the core loop and patches one of them.

DAPO

Fixes stability. Looser rules for boosting good answers, and drops groups that are all-right or all-wrong.

GSPO

Fixes long answers. Judges each answer as a whole instead of word by word, so length cannot distort the signal.

Dr. GRPO

Fixes wasted effort. Focuses learning on the words that actually matter, not common filler the model already knows.

2-GRPO

Fixes cost. Uses just two answers per prompt and still matches larger groups, cutting generation work sharply.

GDPO

Fixes mixed goals. Balances several rewards (say, correctness and format) so a loud one cannot drown out the rest.

GOPO

Fixes fuzzy scores. For judged tasks, uses only the rank order of answers, ignoring unreliable raw numbers.

The pattern None of these reinvents GRPO. Each spots one way the group comparison can go wrong and quietly corrects it.
