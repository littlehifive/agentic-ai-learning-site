7.2 Score each one

It shines when right and wrong can be checked

GRPO is happiest when the reward is a plain fact, not an opinion. If you can run a test and get a clean yes-or-no, you have a perfect signal: correct answers get a 1, wrong ones get a 0, no judge required.

Math

Does the final number match the known answer? One comparison settles it.

Code

Run the test suite. Either the tests pass or they do not; the reward writes itself.

Structured tasks

Any task with a checkable rule: valid format, a puzzle solved, a constraint met.

Think of it like grading a multiple-choice test with an answer key versus grading an essay. The answer key is instant and never argues; that is the kind of reward GRPO thrives on.

In plain terms

Verifiable rewardA score you can compute by checking a fact, not by asking a model or a person to judge.
Why it matters hereA clean, honest signal makes the group comparison trustworthy and removes a whole source of noise.
