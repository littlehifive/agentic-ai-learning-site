7.4 Group size analysis

How many answers? Not too few, not too many

The group size is the main dial. Too few answers and the comparison is a coin flip; too many and you burn compute for little extra signal. There is a comfortable middle.

2 to 4

Cheap but noisy

Fine for quick experiments and easy tasks, but the average is unstable when based on so few answers.

8

The default

A good balance of clear signal and reasonable cost. The standard starting point for most tasks.

16+

For hard problems

Worth it on tasks the model rarely gets right, where you need many tries to land any correct answer at all.

In plain terms

The catchA group must contain both wins and losses. If every answer is right (or every one wrong), they all match the average and there is nothing to learn from.
Goldilocks ruleFeed the model questions it gets right some of the time, neither always nor never, so each group has a real spread.
