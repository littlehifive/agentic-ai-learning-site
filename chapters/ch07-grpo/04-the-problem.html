7.1 Motivation

The scoring model was the weakest link

PPO ran a second network, the critic, whose only job was to predict how good a half-finished answer would turn out. For language that turned out to be a costly, error-prone idea on three fronts.

It costs memory

The critic is roughly the size of the model itself. Keeping both in memory can double the hardware bill, which bites hardest on the largest models.

It is hard to get right

Guessing the final score of a sentence that is only half written is genuinely hard. A wrong guess points the update in the wrong direction.

It is slow to settle

The critic needs many examples before its guesses are stable. Early in training it is noisy, and that noise rattles the model it is supposed to guide.

In plain terms

Critic / value modelIn PPO, a second network that predicts the reward an answer will earn; the bar each choice is judged against.
GRPO's moveReplace that prediction with a real measurement: the average reward of a group of answers to the same prompt.
