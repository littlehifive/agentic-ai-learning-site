26.5 Generative UI

The agent can build the interface, not just the words

Normally a model returns text or markdown. Generative UI flips that: the model picks a ready-made component, a chart, a form, a map, a calendar, and fills it with the answer. It chooses not only what to say but how to show it, based on the kind of content.

Text only

Today in Lisbon it is 21 degrees and sunny. This week peaks Thursday at 27 degrees, with a dip Saturday to 18 degrees.

Generated widget

Lisbon · Sunny

21°

Think of it like a good assistant who, asked about the weather, does not read you a paragraph of numbers but hands you a clean little forecast card you can read at a glance.

In plain terms

Generative UIThe model's tool calls produce interface pieces, so the display adapts to the content.
Curated componentsFor safety it picks from a vetted library rather than inventing raw, untrusted markup.
