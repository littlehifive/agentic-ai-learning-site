26.3.2 Tool use visualization

Show what the agent ran and what it got back

Tool calls are how an agent touches the world: search the web, run code, read a file. Each call is worth showing in four parts: the tool name, the input, the result, and how long it took. That provenance is what lets a person verify a claim or spot where things went wrong.

web_search in: "rainfall Kenya 2024" → out: 8 results 342 ms · ok
run_python in: mean of column "yield" → out: 4.12 128 ms · ok
read_file in: /data/notes.csv → out: file not found 12 ms · error
Think of it like a receipt for every errand. Instead of "trust me, I handled it," you get an itemized list of what was done, with what, and the outcome, so a failed line stands out at once.
