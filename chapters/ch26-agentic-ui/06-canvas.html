26.2 Canvas and artifact-based interfaces

A shared workspace you and the agent edit together

The canvas splits the screen: chat on one side, a live document on the other. The result stays put across turns, you can edit it directly, the agent can react to your edits, and a version history lets you roll back. It suits co-creation: writing, coding, and analysis.
