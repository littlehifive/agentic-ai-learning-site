26.1 Motivation: beyond the chat box

An agent is a collaborator, not a vending machine

A vending machine takes your input and hands back one result. An agent might browse the web, write and run code, and work for minutes. To stay a partner rather than a black box, its interface has to answer the questions a person naturally asks while watching someone work.

✓What is it doing right now? Long tasks need progress; silence breeds distrust.
✓Why did it decide that? Showing the reasoning lets people catch errors early.
✓Which tools did it use? Knowing the inputs lets people verify the claims.
✓Where should I step in? Surface the decisions that truly need a human.
✓Can I undo this? Sending mail or changing files needs confirmation and a way back.
✓How sure is it? People over-trust confident machines, so the UI must show doubt.

In plain terms

Automation biasThe human habit of over-trusting a confident machine; good agent UIs fight it by showing uncertainty.
Five design goalsTransparency, control, trust calibration, efficiency, and recoverability.
