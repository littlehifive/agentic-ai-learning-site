26.2 UI paradigms for agents

One size does not fit all: a spectrum of interfaces

The right interface depends on how long the task runs, how much human involvement it needs, and what kind of output it produces. These six paradigms run from fully conversational to nearly autonomous, and most real products blend several of them.

Chat
Conversational
Familiar message bubbles, now with streaming and inline tool badges. Easy to start, but it flattens parallel work into one line.
Canvas
Shared artifact
Split pane: chat plus a live, editable document. Best for writing, coding, and analysis.
Workflow
Plan as a graph
The agent's steps drawn as a flowchart, nodes lighting up as they run. Good for structured pipelines.
Dashboard
Operator view
Status, cost, and queues for long-running production agents. Aimed at operators, not end users.
Collaborative
Agent as peer
The agent appears as a labeled cursor in a shared doc, proposing tracked edits you accept or reject.
Autonomous
Runs with checkpoints
The agent works mostly on its own and only surfaces at approval points before irreversible steps.
