20.3.1 Code execution sandboxes

An environment is a sandbox world the agent can poke at

It is a safe, walled-off copy of something real: a browser, a computer desktop, or a code repository. The agent takes an action, the world changes and shows the result, and the agent acts again. The same simple loop repeats until the task is done.

Start fresh → Agent acts → World responds → Agent sees result ↻ Repeat until done
Think of it like a flight simulator for agents. A pilot in training crashes the simulator a hundred times to learn, with no one hurt and no plane lost. The sandbox is that simulator: the agent can fail, recover, and learn without touching a real database or live website.

In plain terms

SandboxA walled-off copy of a real system where mistakes do no lasting harm.
ActionA move the agent makes: click a button, run some code, type a command.
ObservationWhat the agent gets back after acting: the new screen, the program output, an error.
