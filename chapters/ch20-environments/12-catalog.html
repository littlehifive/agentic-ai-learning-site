20.9 Comparison of major agentic environments

The four worlds, side by side

WebArena · the web

  • World: a live browser on real web apps.
  • Task: shop, post, look things up across pages.
  • Score: people 78%, best agents about 45%.

SWE-bench · code

  • World: a real open-source repository with a bug.
  • Task: write a patch that makes the tests pass.
  • Score: engineers 100%, best agents about 50%.

OSWorld · the desktop

  • World: a full computer, seen on screen.
  • Task: run everyday apps by mouse and keyboard.
  • Score: people 72%, best agents about 18%.

GAIA · general help

  • World: open tasks needing several tools.
  • Task: chain search, code, and files into an answer.
  • Score: people 92%, later agents about 30%.
The pattern: the gap to human level is smallest for code, where models have seen mountains of training data, and largest for desktop control, where screen-and-click data is still scarce.
