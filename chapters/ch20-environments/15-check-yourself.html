Why can't you test an agent the way you test a chatbot?

Reveal ▸

A chatbot is judged on one reply. An agent has to act over many steps, observe results, and adapt. Only a structured world, an environment, can capture whether it reliably gets goals done.

What is execution-based reward, and why is it hard to game?

Reveal ▸

It scores the agent by running the result and checking it, do the tests pass, is the cart correct, rather than by reading its words. There is no wording to hide behind, so the agent cannot talk its way to a pass.

Which benchmark fixes real GitHub bugs, and how is it graded?

Reveal ▸

SWE-bench. The agent patches a real codebase, and a hidden test suite is run. It scores 1 only if every test passes, with no partial credit, which is why it is so demanding.
