20.2 Environment design principles

A good environment gets four things right

Building one is a craft. Each of these four choices has a failure mode that can quietly ruin a whole benchmark, so designers tune all four together.

1What the agent sees

The observation: plain text, structured data, or a screenshot. Show too much, like sneaking in the answer, and scores look great but the agent collapses in the real world.

2What the agent can do

The action space: run code, call a tool, click and type, send a message. This defines the agent's whole repertoire of moves in this world.

3How it is scored

The reward signal. The hardest part to get right: it must reward real success, give enough feedback to learn from, and resist being gamed.

4When it ends

The episode structure. A fixed number of steps, stop when the agent says it is done, or run until a budget of time or money runs out.

In plain terms

Observation leakageAccidentally letting the agent peek at the answer, which fakes a high score.
EpisodeOne full attempt at a task, from a fresh start to a finish or a cutoff.
