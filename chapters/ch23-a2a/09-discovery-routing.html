23.4 Agent discovery and routing

Before it can delegate, an agent has to find the right one

A registry is a directory that indexes Agent Cards and answers search queries. An orchestrator looks up agents by the skill it needs, instead of hardcoding any addresses, then picks the best match for the job.

Step 1

Look up

Query the registry for agents whose cards list the required skill.

→

Step 2

Match

Compare the task to each candidate's description and pick the closest fit.

→

Step 3

Balance

If several agents qualify, spread load by who is least busy or fastest.

→

Step 4

Dispatch

Send the task to the chosen agent and track it through its lifecycle.

Think of it like a staffing agency. You describe the role, it searches its roster of profiles, shortlists the best fit, and assigns whoever is available, all without you knowing anyone's phone number in advance.

In plain terms

RegistryA searchable directory of Agent Cards that says who can do what.
Load balancingSpreading work across equally able agents so none gets overwhelmed.
