23.1 Motivation: why agents must communicate

One agent cannot be both broad and deep

A generalist agent runs into a wall: real tasks like legal review or scientific research need both wide knowledge and deep skill. The fix is a network of specialists, each handling the part it is best at and handing off the rest.

+ Context limits. Each model has a finite memory; splitting work keeps every agent within a manageable load.
+ Specialization. A code agent, a legal agent, a data agent: route each subtask to the right expert.
+ Parallelism. Independent subtasks run at once across many agents, cutting wall-clock time.
+ Resilience. If one agent fails, the system can retry elsewhere, fall back, or escalate to a human.
Think of it like a general contractor on a building site. They do not lay every brick themselves; they call in an electrician, a plumber, and a roofer, each doing one job well.

In plain terms

OrchestratorThe lead agent that breaks a goal into parts and hands them out.
Specialist agentAn agent tuned or equipped for one kind of work, such as code or data.
