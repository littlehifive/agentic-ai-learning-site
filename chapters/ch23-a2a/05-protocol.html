23.2 The Google A2A protocol

An open standard for agents to talk as peers

In April 2025, Google and over 50 partners released the Agent-to-Agent protocol, later donated to the Linux Foundation. It deliberately reuses plumbing every team already runs: HTTP, JSON messages, and standard streaming, rather than inventing new transports.

Opaque execution

A caller never peers inside a remote agent. Whether it runs one model or another is irrelevant; only the declared interface matters.

Enterprise ready

Authentication, audit logging, and compliance are built into the protocol from the start, not bolted on later.

Async first

Long-running work is the norm. A caller never has to hold a connection open for hours waiting on a result.

Think of it like shipping a parcel through a courier. You do not need to know how their trucks work, only the address label and the rules everyone agrees to follow.

In plain terms

ProtocolA shared set of rules for how two systems exchange messages.
Open standardA spec anyone can adopt freely, so no single company controls it.
