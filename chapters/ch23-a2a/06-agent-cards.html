23.2.2 Agent Cards

Every agent publishes a public profile

An Agent Card is a small, machine-readable file an agent hosts at a well-known address. It advertises what the agent can do, how to authenticate, and where to send work, so others can discover and call it without any hardcoded wiring.

The card lists named skills, each with example prompts, so an orchestrator can read it and decide, on its own, which agent fits a given subtask.

Because the card declares the auth scheme and endpoint, the calling agent knows exactly how to connect, with no out-of-band setup.

Drop a card into a registry and the agent becomes discoverable to the whole network at once.

Think of it like a LinkedIn profile or a business card for an agent. It says who I am, what I am good at, and how to reach me, so the right work finds its way to me.
