17.11 Recent advances in agentic memory

Named systems that put this into practice

The ideas in this chapter are not just theory. A handful of well-known systems show how they come together, from reference frameworks to production layers.

CoALA

Reference framework

Organizes the zoo of agents around the same four memory types and a read-act-reflect-write cycle. A shared design language for analyzing and comparing agents.

Generative Agents

Observation and reflection

Stores observations as time-stamped objects with importance scores, retrieves them with a recency bias, and reflects to form higher-level beliefs.

Mem0

Production memory layer

Extracts salient facts from conversation automatically, keeps a relational graph over them, and merges duplicates, cutting cost and latency versus stuffing everything into context.

A-MEM

Self-organizing notes

Stores richly tagged, interlinked notes that update one another as the agent learns, so memory becomes a living network rather than a flat list.
