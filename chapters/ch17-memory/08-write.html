17.4.1 Write: committing to memory

Storing everything is the same as storing nothing

A memory crammed with every passing observation is unsearchable. So the write step is a filter: an item is kept only if it looks important enough, and a new fact is checked against what is already stored before it goes in.

Gate by importance

An item is written only if it clears a bar. Importance can be measured by surprise (the unexpected is informative), by how strong a reward or penalty it carried, or by simply asking the model to rate it. Routine, low-signal observations are dropped.

Catch contradictions

Before a new fact is saved, the system checks whether it conflicts with an existing one. On a clash it must choose: overwrite the old, keep both with timestamps, or flag it for a human to settle.

Think of it like a good note-taker, not a tape recorder. They jot the decisions and the surprises, skip the small talk, and cross out a note when a later one overrides it.

In plain terms

Importance gateA threshold that blocks low-value items so the store stays useful.
ProvenanceA link from each entry back to its source, so the agent can verify and the user can audit.
