17.4 Memory operations

Memory runs on a four-step cycle

A memory system is not just a store; it is a set of actions the agent performs around it. Before responding it reads; after responding it decides what to keep, what to merge, and what it has learned.

Write

Decide what to keep

Not everything is worth storing. A write happens only when an item clears an importance bar, which keeps the store from filling with noise.

Read

Retrieve what fits

Given the current situation, pull back the most relevant past items by similarity, weighted toward recent ones.

Update

Consolidate and reconcile

Merge related entries, resolve contradictions when a new fact conflicts with an old one, and forget what is no longer useful.

Reflect

Turn events into insight

Read across many episodes and distill a lasting lesson, then file that lesson as durable general knowledge.
