17.2 Memory type classification

One coding agent, all four at once

The categories are not abstract. Watch a single agent helping with software development draw on each kind of memory in the same moment.

Working The file open in the editor and the error message it just received. Live in the context window.
Episodic "Last week I fixed a similar null error in module X by adding a check at line 42." A specific recalled event.
Semantic "Running tasks concurrently lets exceptions surface unless you ask to collect them." A general fact, no episode attached.
Procedural The standard debugging routine it follows by habit: reproduce, isolate, hypothesize, test, fix.
