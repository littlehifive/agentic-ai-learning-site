17.1 Motivation: why agents need memory

The context window is finite, and it resets

A model can only attend to a fixed window of recent text. A long-running agent piles up observations, tool outputs, and reasoning far beyond that window. Once something scrolls out, it is gone, and the next session starts cold. Memory is the engineering answer to that hard limit.

Think of it like a worker with no long-term recall and a small desk. Only what fits on the desk right now can be used; everything else falls off the edge unless it is filed somewhere it can be fetched again later.

In plain terms

Context windowThe fixed amount of text a model can read at once. Large but never unlimited.
StatelessEach call begins from nothing; the model keeps no record of earlier calls on its own.
Memory systemExternal storage plus rules for writing and retrieving, so the agent can refer back.
