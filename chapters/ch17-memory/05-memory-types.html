17.2 Taxonomy of memory types

Four kinds of memory, mirroring human memory

Cognitive science splits memory into distinct systems, each with its own access pattern. Agent memory borrows the same four categories, because they map onto genuinely different storage and retrieval needs.

Working memory

What the agent is actively manipulating right now: its scratchpad, its chain of reasoning, the current conversation. Fast and free to use, but volatile and bounded by the window.

Like what is on your mind this moment, before it slips away.

Episodic memory

Specific past events indexed by time and context: prior conversations, successful attempts, documented failures. Retrieved when a new task resembles an old one.

Like recalling a particular event you lived through.

Semantic memory

General facts and concepts, stripped of any single episode. Definitions, entities, relationships. True regardless of when or where they were learned.

Like knowing a fact without remembering learning it.

Procedural memory

How to do things: learned tool-use patterns, multi-step workflows, action sequences that have become routine. Often baked into the model weights themselves.

Like a skill your hands just know, such as riding a bike.
