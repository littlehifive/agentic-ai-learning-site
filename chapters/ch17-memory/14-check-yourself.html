Why does an agent need memory at all if the model is so capable?

Reveal ▸

Because the model is stateless and its context window is finite. It starts each call from scratch, and anything that scrolls out of the window is lost. Memory is the external system that lets the agent keep and retrieve what matters across steps and sessions.

What is the difference between episodic and semantic memory?

Reveal ▸

Episodic memory holds specific past events tied to time and context, such as "last week I fixed this exact bug." Semantic memory holds general facts with no episode attached, such as "this error type means a value was missing." Reflection is how the first turns into the second.

How is MemGPT like an operating system?

Reveal ▸

It treats the limited context like fast RAM and external storage like slow disk, then pages items between them. The agent promotes relevant, important, recent items into context and evicts the rest, so a small window can serve a huge store, just as virtual memory does.
