17.4.4 Reflect: meta-cognitive operations

Reflection turns scattered episodes into a durable lesson

After repeated failures, an agent can read its own history, spot the common thread, and write down a general rule. Next time, that rule is retrieved and acted on. This is how an episode becomes lasting knowledge.

Input

Episodic memory

Retrieve the specific past events, such as three failed attempts at the same coding problem.

→

Compute

Working memory

In context, reason across them and name the pattern: "I keep skipping the empty-input case."

→

Output

Semantic memory

Store the generalized insight: "Always check for empty inputs." It now applies to any future task.

Think of it like a person reviewing a rough week and concluding "I should sleep before big decisions." The specific bad days fade; the rule stays. This mirrors how the brain turns experience into knowledge during rest.
