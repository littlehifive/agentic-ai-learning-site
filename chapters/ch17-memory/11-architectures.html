17.3 Memory architectures

Five ways to actually store and fetch

The four memory types describe roles. These are the engineering forms that fill those roles, each with a different trade-off between capacity, speed, and structure.

Retrieval-augmented (RAG) Store items as numeric embeddings; fetch the closest matches to a query. The dominant pattern for episodic and semantic recall.
Summarization-based Compress as you go into a running or layered summary. Keeps memory small, at the cost of losing detail.
Graph-based Store facts as linked entities and relations. Lets the agent follow connections and answer multi-step questions.
Key-value networks Differentiable slots retrieved by attention. Can be trained end to end; modern attention is a special case.
Tiered virtual context (MemGPT) Hot, warm, and cold tiers with paging between them. Built for long-horizon agents and assistants.
