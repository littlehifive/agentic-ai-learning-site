Why does a shared protocol beat custom connectors?

Reveal ▸

Custom wiring grows by multiplication: every agent needs a connector to every tool, so the count explodes. A shared protocol grows by addition: each side learns the plug once. N times M becomes N plus M.

What are the three roles, and who does what?

Reveal ▸

The host is the app you run and the one in charge. Inside it, each client holds one connection to one server. A server is the small program that exposes a tool or data source. Picture a dining room, a waiter, and a kitchen.

Why is consent built into MCP?

Reveal ▸

Because a connected tool can take real actions like deleting files or sending messages. The host must ask the user before anything irreversible and treat outside data as untrusted, since hidden instructions could try to hijack the model.
