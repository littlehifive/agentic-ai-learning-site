21.3 Core primitives

Four things a server can offer: tools, resources, prompts, sampling

A server exposes its capabilities through four building blocks. Three of them flow toward the model; the fourth flows the other way, letting a server borrow the model's brain when it needs to.

Tools Actions the model can call: create a file, send a message, run a query. These do things and can have side effects. Model actsmodel calls the server
Resources Data the model can read: file contents, database records, API responses, pulled in to inform the answer. Model readsserver provides data
Prompts Reusable templates the server author writes once, such as a "review this pull request" prompt, ready to drop in. Ready-madeserver offers a template
Sampling The reverse direction: the server asks the model for help, for example to summarize data before returning it. Server asksserver calls the model
Think of it like a workshop. Tools are the power tools you operate, resources are the reference manuals on the shelf, prompts are the pre-printed job checklists, and sampling is the workshop phoning the office for a quick decision.
