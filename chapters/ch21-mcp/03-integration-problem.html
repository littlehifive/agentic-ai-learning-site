21.1 Motivation: the tool integration problem

Every agent times every tool is a connector you have to build

Take 3 agents and 3 tools. Wire each agent directly to each tool and you need 9 custom connectors. Add a shared plug in the middle and you need just 6, one per side. The gap only widens as the numbers grow.
