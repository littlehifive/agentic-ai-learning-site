21.2 Concrete example: a coding assistant

One question, three servers, answered together

A developer uses a code editor powered by an LLM. The editor is the host, and it runs three clients, each connected to a different server. One request can reach all three at once, through the same standard calls.

The developer asks "Fix the bug in auth.py that is causing the login failures shown in issue #42."

Filesystem server

Reads auth.py so the model can see the actual code.

GitHub server

Fetches issue #42 to learn what the failure looks like.

Database server

Runs a read-only query to pull the relevant login logs.

Think of it like a single waiter taking your order to three kitchens at once: the bakery, the grill, and the bar. You ask once, and the plates arrive together.
