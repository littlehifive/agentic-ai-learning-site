6.3 Gradient analysis

Learning concentrates on the pairs it gets wrong

The update built into DPO weighs itself automatically. It leans hardest on examples where the model currently prefers the worse answer, and barely moves on examples it already gets right. The hard, confusing pairs get the attention.

Model picks the wrong one

The gradient is strong. The model is confidently mistaken here, so training pushes hard, raising the chosen answer and lowering the rejected one until the order flips.

Model already picks the right one

The gradient is tiny. The chosen answer is already ahead by a healthy margin, so there is little to fix and training mostly leaves it alone, avoiding overfitting.

Think of it like a teacher with limited time. Spend it on the questions students keep missing, not the ones they already ace. DPO spends its learning budget the same way.

In plain terms

GradientThe size and direction of each training nudge to the model.
Adaptive weightBigger nudges on confusing pairs, near-zero on ones already learned.
