How much control you hand over

Autonomy is a dial, not a switch

Building with these models is not all-or-nothing. You can ask for a single answer, script the steps yourself, or let the model decide its own steps. More autonomy buys flexibility but costs predictability.

Least autonomy

Single call

One prompt, one response. Fast and predictable, but it cannot react to results or take any action.

You decide everything

→more flexible

Middle ground

Workflow

You lay out the steps in advance and the model fills each one in. The path is fixed, so it stays easy to test and to trust.

You set the steps

→less predictable

Most autonomy

Autonomous agent

The model chooses its own steps in the loop, deciding what to do and when to stop. Powerful for open-ended tasks, harder to predict and govern.

The model decides the steps

The guiding principle Prefer the simplest design that works. Reach for a fixed workflow until the task genuinely needs the model to chart its own course, then add autonomy only where it pays for itself.
