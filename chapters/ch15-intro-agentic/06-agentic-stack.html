To address these challenges, a layered architecture

Production agents are built as a stack of layers

A reasoning model sits at the center. Around it, each layer solves one specific problem. You add only the layers a task needs. This is the map for the rest of Part V, covered bottom to top.

Chapter 16 Grounding · RAG Retrieve outside knowledge at query time, so the agent can use data it never trained on.
Chapter 17 Persistence · Memory Recall information across steps and sessions, from short-term notes to long-term history.
Chapter 18 Runtime · Harness The agent's operating system: it runs the loop and decides when to retrieve, call a tool, or ask a human.
Chapters 19 to 20 Patterns · Evaluation Proven ways to structure an agent, and how to test multi-step behaviour in real environments.
Chapters 21 to 24 Tools · MCP and Multi-Agent A standard way to plug in tools, and protocols for many specialist agents to work together.
Chapters 25 to 26 Frameworks · Agentic UI Toolkits that implement the stack, and the interfaces people use to supervise and steer agents.
Think of it like a network stack. No single layer does the whole job, but stacked together they form one integrated system, and a weak layer drags the rest down with it.
