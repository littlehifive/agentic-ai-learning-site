Chapter 3 · Agent-environment interaction loop

One loop underneath: observe, act, get reward, repeat

At every step the agent sees the current situation, picks an action, the world changes, and a reward arrives. Run this loop for thousands of steps and the agent learns which actions lead to the most reward over time.

Step 1

Observe

Read the current state of the world, what things look like right now.

→

Step 2

Act

Choose an action using the policy, the agent's current strategy.

→

Step 3

Transition

The environment moves to a new state in response to that action.

→

Step 4

Reward

A single number scores the move, the only feedback the agent gets.

Use the reward to nudge the policy then observe the new state and go again

In plain terms

AgentThe learner and decision maker; the thing whose behaviour we are training.
EnvironmentEverything outside the agent that it acts on and that responds with new states and rewards.
RewardA scalar signal saying how good the last move was. Maximising total reward is the whole goal.
