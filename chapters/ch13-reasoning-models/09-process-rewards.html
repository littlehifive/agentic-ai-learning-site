13.4.2 Process reward models

A judge that grades the working, not just the answer

Search needs a way to tell promising steps from dead ends. An outcome judge only checks the final answer, so it cannot say which step went wrong. A process reward model scores each step along the way, giving the search a signal at every fork about which branch is worth following.

Outcome reward: grade the result

Looks only at the final answer and marks it right or wrong. Clean and unambiguous, but if a fifty-step proof has one early slip, the whole thing gets a zero with no hint about where it broke.

Process reward: grade each step

Scores every reasoning step for whether it still looks on track. This guides search toward solutions that are sound the whole way through, and is especially useful for picking the best of many candidate solutions.

Think of it like a maths teacher giving marks for method, not just the final number. Partial credit at each line tells the student exactly where the working went astray, instead of a bare cross at the bottom.

In plain terms

Outcome reward (ORM)A score for the final answer only.
Process reward (PRM)A score for each step, so the search knows which branch is healthier.
The tensionStep scores help guide search, but can be gamed, so step-level grades that look good are not always genuinely correct.
