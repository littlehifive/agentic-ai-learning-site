19.1.2 Workflow patterns: routing

Classify the request, then send it to the right handler

One classifier looks at the input once and decides what kind of request it is. It then dispatches the work to a specialist tuned for exactly that type, each with its own prompt, tools, or model.

Classifier

Reads the input once and labels its type.

→
Billing questionAccount and payments specialist.
Technical issueTroubleshooting specialist with tools.
General queryFast, low-cost default handler.
Think of it like a front desk that triages arrivals. One person asks a quick question, then points you to the right department instead of trying to solve everything at the desk.

In plain terms

ClassifierA model or simpler rule that puts each request into a category.
Best forDistinct task types that each deserve a different prompt or model: support triage.
