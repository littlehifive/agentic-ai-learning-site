What is the difference between a workflow and an autonomous agent?

Reveal ▸

In a workflow you fix the steps and the model just fills them in, so the order is predictable and testable. In an autonomous agent the model decides what to do next. The dividing line is who controls the order of work.

How does orchestrator-workers differ from parallelization?

Reveal ▸

Both split work across several calls. In parallelization you decide the subtasks in advance. In orchestrator-workers the model studies the task and invents the subtasks itself at run time, which suits jobs you cannot break down up front.

When should you add autonomy instead of using a fixed workflow?

Reveal ▸

Only when a simpler pattern has visibly failed on real inputs. Autonomy costs more calls, more latency, and is harder to debug, so start with the simplest design that works and climb the ladder one rung at a time.
