11.1 The 4-Model Memory Challenge

Tuning a model with feedback means running four models at once

Ordinary training keeps one model in memory. Learning from human feedback is different: four separate models must all sit in GPU memory together, working in a tight loop of generate, score, and update.

The learner

Policy

The model being improved. It writes answers and is updated after each round.

The anchor

Reference

A frozen copy of the starting model. It keeps the learner from drifting too far.

The judge

Reward

Scores each answer for quality, standing in for human preference.

The estimator

Value

Predicts how good a situation is, so the learner knows which answers beat expectations.

Think of it like a writing student (policy) with an editor giving notes (reward), a coach predicting how a draft will land (value), and the student's own earlier style on the wall (reference) so they do not lose their voice. All four are in the room together.

In plain terms

RLHFReinforcement learning from human feedback: teaching a model what people prefer by rewarding better answers.
Why it is hardFour models in memory at once is many times the size of training just one, so it overflows a single GPU fast.
