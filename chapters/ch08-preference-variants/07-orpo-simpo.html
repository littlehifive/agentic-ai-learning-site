8.4 ORPO and SimPO · reference-free methods

Drop the second model to halve the memory

The problem they fix: every method so far keeps a frozen reference copy of the model in memory to stop it drifting. That doubles the footprint. Both of these methods get the same anchoring without the spare copy, so you train with one model instead of two.

ORPO

Folds preference alignment straight into ordinary fine-tuning, in one loss and one training run. The fine-tuning part keeps the model honest, which is the job the reference model used to do. No separate alignment step, and roughly half the memory.

SimPO

Scores an answer by its own length-adjusted likelihood rather than by comparing against a reference. Same reference-free goal as ORPO, reached a different way. It strips the spare model out of the standard DPO loss.

Think of it like learning to ride without training wheels. The reference model was the stabilizer; these methods build the balance into the rider, so you carry less hardware around.

In plain terms

The fixNo reference model, so about fifty percent less memory and a simpler pipeline.
