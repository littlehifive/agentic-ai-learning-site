You only have thumbs-up and thumbs-down data, no pairs. Which variant fits?

Reveal ▸

KTO. It learns from a single label on each answer, so it never needs a matched good-and-bad pair. That makes raw production feedback usable as-is.

Why do ORPO and SimPO use less memory than DPO?

Reveal ▸

They drop the frozen reference model that DPO keeps as a second copy. ORPO folds the anchoring into fine-tuning and SimPO uses the answer's own length-adjusted likelihood, so one model does the whole job.

Best-of-N does no training. How does it still improve answers?

Reveal ▸

It generates several answers and a scorer keeps the best one. Picking from many drafts raises quality without changing weights, and those winners can later be fine-tuned on for a lasting gain.
