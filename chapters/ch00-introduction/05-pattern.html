The pattern behind every leap

Three ingredients keep producing breakthroughs

Architecture innovation

A new design for the model itself, like attention, that lets it learn things older designs could not.

+

Scale

More data and more computation. Bigger models trained on more text reliably get better.

+

Learning signal

What the model learns from: game outcomes, internet text, human preferences, or verified rewards.

→ a breakthrough
Deep Blue searched by hand, AlphaGo learned from self-play, GPT-3 learned from the internet. The learning signal keeps getting richer, and the architectures grow to match.
