The cost of attention at generation time

Two tricks keep long conversations affordable

Attention is powerful but memory-hungry. As text gets longer, the model needs ways to avoid redoing work and to stop its memory from ballooning.

The KV cache

When generating, the model would otherwise recompute its view of every earlier word at each step. Instead it saves that work in a cache and reuses it, so each new word is cheap. The catch: the cache grows with the length of the conversation.

Grouped-Query Attention (GQA)

The cache is dominated by the per-head keys and values. GQA lets several attention heads share one set of keys and values instead of each keeping its own, shrinking the cache roughly fourfold with almost no loss in quality.

Think of it like a scratchpad of notes from earlier in the chat. The KV cache is the scratchpad; GQA is agreeing that several readers can share one copy of the notes instead of each printing their own.

In plain terms

KV cacheSaved results for earlier words so the model does not recompute them every step.
GQAHeads sharing keys and values to cut that memory, with negligible quality cost.
